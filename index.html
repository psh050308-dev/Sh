wiw 아지트

데모 화면이에요. 구글 로그인과 실제 위치 확인은 사이트를 배포하면 켜지고, 지금은 예시 친구들과 위치 시뮬레이션으로 동작을 미리 볼 수 있어요.

구글 계정으로 들어오기

  1. 로그인하고 내 캐릭터를 만들면 3D 아지트에 들어가요. 내 출석부도 자동으로 생겨요.
  2. 아지트에 와서 사이트를 열면 체크인되고 그날 출석 도장이 찍혀요.
  3. 방 안의 출석부에 다가가 살펴보면 출석부가 열려요. 오늘 칸에 그림과 코멘트를 남길 수 있어요.

내 정확한 위치는 저장하지 않아요. 아지트 안인지 아닌지만 기록돼요.

초대 코드를 입력해 주세요

처음 한 번만 입력하면 돼요. 코드는 아지트 친구에게 물어보세요.

      위치 확인 켜기

      사이트를 열면 폰 위치로 아지트 도착 여부를 확인해요. 좌표는 폰 안에서만 계산하고, 서버에는 "아지트에 있음/없음"과 시각만 저장돼요. 언제든 끌 수 있어요.

      위치 확인 대기 중

      위치 시뮬레이션 (데모 전용)

      이렇게만 하면 돼요

      • 아지트에 오면 이 사이트(홈 화면 아이콘)를 열기만 하세요. 자동으로 체크인되고 출석 도장이 찍혀요.
      • 문 앞 스티커에 폰을 대거나 QR을 찍어도 똑같이 체크인돼요.
      • 다른 곳에서 열면 자동으로 체크아웃되고, 오래 확인이 없으면 방에서 저절로 빠져요.
      더 자동으로 (선택, 폰 설정 필요)

      사이트를 열지 않아도 체크인되게 하고 싶을 때만 쓰세요. 폰의 위치 자동화가 아지트 도착 때 아래 주소를 열어 줘요.

      도착할 때 열 주소

      떠날 때 열 주소

      아이폰 (단축어 앱)

      1. 자동화 → 새로운 자동화 → 도착
      2. 위치에 아지트를 검색해 지정하고 반경 조절
      3. 즉시 실행 선택 → 동작 URL 열기에 도착 주소
      4. 같은 방법으로 출발 자동화에 떠날 때 주소

      갤럭시 (모드 및 루틴)

      1. 루틴 추가 → 조건 장소에 아지트 지정
      2. 동작 웹 주소 열기에 도착 주소
      3. 루틴 종료 시 동작에 떠날 때 주소
